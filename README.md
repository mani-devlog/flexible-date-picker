# FlexibleDatePicker

Flexible date and time pickers for **Angular 20+** — eight standalone components (date, time, month, year in single and range modes), headless selection engines, reactive forms support, light/dark theming, and locale/RTL layout.

Install from npm:

```bash
npm install @manidev/ngx-flexible-date-picker date-fns
```
